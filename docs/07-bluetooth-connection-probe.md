# 07 · 蓝牙设备连接验证

这个工具用于验证：不用 Android App，是否可以直接使用已配对蓝牙设备的连接变化作为后续自动解锁的触发信号。手机、蓝牙鼠标、键盘等均可选择，枚举同时覆盖经典蓝牙和 BLE。

当前阶段只记录，不把连接状态接入自动解锁，也不主动连接设备。原有 BLE 广播方案保留。

## 使用

1. 在 Windows 蓝牙设置中配对设备。鼠标/键盘须使用蓝牙模式；2.4G USB 接收器、普通 USB 有线设备不在此范围。
2. 打开 BTUnlock 主窗口的“蓝牙设备连接验证（无需手机 App）…”。
3. 点击“刷新已配对设备”，通过名称和蓝牙地址选择目标设备，点击“开始记录”。如有多个同名条目，分别测试各端点。
4. 确认日志出现 `START`、`ADDED` 和 `ENUMERATION_COMPLETED`。`ADDED` 记录的初始连接状态不计为重连。
5. 按下方流程测试。可输入测试标记并点击“添加测试标记”，记录静置、离开、关机等操作。
6. 关闭验证窗口只隐藏界面，程序仍在托盘记录。再次点击主窗口入口可恢复；点击“停止记录”或退出程序结束记录。

**记录期间暂停 BTUnlock 原有自动锁屏和自动解锁，停止记录后恢复原设置。** Windows 动态锁及系统锁屏策略不受影响，主界面“立即锁屏（测试）”仍可使用。需要持续锁屏的测试，可先关闭主界面实验性解锁开关，避免停止记录后恢复旧解锁逻辑。

## 建议验证流程

| 步骤 | 操作 | 需要观察 |
|---|---|---|
| 在场基线 | 手机息屏或鼠标/键盘静置至少 5 分钟，尽量覆盖设备休眠时间 | 是否人在旁边也断开；断开前是否需要真实通信 |
| 离开/断开 | 携带目标设备走出蓝牙范围；也可额外测试关闭设备电源 | 是否出现明确的已连接→未连接，以及报告延迟 |
| 锁屏返回 | 保持 BTUnlock 运行，手动 `Win + L`，将设备带回或重新开机 | 是否在解锁之前自动出现未连接→已连接 |
| 唤醒对比 | 对鼠标分别测试不触碰、移动或按键唤醒 | 是否必须先唤醒外设才能重连 |
| 重复 | 至少重复三轮，并覆盖电脑睡眠/唤醒 | 是否稳定重现，是否需要在系统设置中手动连接 |

电脑锁屏和睡眠不同：锁屏时程序可继续运行；电脑睡眠期间不能保证持续记录。恢复后的日志空档不能直接解释为蓝牙断开。

## 日志与解释

每轮生成独立文件：`%APPDATA%\BTUnlock\connection-probes\probe-*.log`，界面支持打开目录。文件保留本轮完整记录，界面只显示最近 300 行；日志写入失败会显示错误。

- `ADDED` / `UPDATED`：Windows 提供的 `System.Devices.Aep.IsConnected` 状态。属性更新未包含连接字段时，不改写连接状态。
- `REMOVED`：目标端点被移出枚举，标记为未知，不将其直接计为确认断开。
- `SESSION SessionLock` / `SessionUnlock`：程序收到的会话锁定、解锁事件。开始记录时会话状态为未知，直到收到事件。
- `HEARTBEAT`：每 15 秒记录当前状态和监听器状态，便于判断锁屏期间程序是否仍运行；这是最近一次系统报告的状态，不是主动探测结果。
- `MARK`：人工测试标记。
- `WATCHER_STOPPED`：系统监听异常停止，需要停止记录后重新开始；此时仍保留诊断模式，避免意外恢复自动解锁。
- `STOP`：本轮结束。连接计数只统计明确的已连接↔未连接变化，经过未知状态的变化不计入。

如果设备一直显示未连接或未知，即使它出现在配对列表，也不能认定该方案可用。若只在手动解锁后出现连接事件，同样不能满足“锁屏期间重连触发解锁”的目标。

蓝牙连接不等同于人在场。鼠标休眠、关机或驱动异常都可能导致断开；鼠标放在桌上也无法表明用户已经离开。因此，即便设备可稳定重连，后续是否采用它来自动锁屏/解锁仍需按实际使用方式决定。Windows 动态锁官方支持的是与手机配合的方案，不能据此推定它会使用任意鼠标。

## 实现依据

工具使用经典蓝牙与 BLE 的已配对设备 AQS 过滤器、`DeviceInformationKind.AssociationEndpoint` 和 `DeviceWatcher`，按选中设备的 ID 过滤事件，不创建 GATT/RFCOMM 连接，不进行配对操作。

- [经典蓝牙配对过滤器](https://learn.microsoft.com/en-us/uwp/api/windows.devices.bluetooth.bluetoothdevice.getdeviceselectorfrompairingstate)
- [BLE 配对过滤器](https://learn.microsoft.com/en-us/uwp/api/windows.devices.bluetooth.bluetoothledevice.getdeviceselectorfrompairingstate)
- [微软设备枚举示例](https://github.com/microsoft/Windows-universal-samples/tree/main/Samples/DeviceEnumerationAndPairing)

本工具的日志是实测依据；代码完成、静态检查或 CI 构建成功均不能证明具体设备在锁屏期间会自动重连。
